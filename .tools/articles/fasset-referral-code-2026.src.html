Referral code not working? Common fixes

  • "Invalid code": you've almost certainly typed the letter O. The code is 0AQ0D2G with two zeros.
  • Forgot to enter it: referral codes can only be applied during signup. They can't be added to an account that already exists.
  • Already have an account: referral campaigns are for new users only.
  • No reward showing: check the referral screen for the qualifying steps. Rewards usually wait on verification and the campaign's required action, such as card activation.
  • Promo code vs referral code: they're different. The referral code goes in at signup, and promo codes go in later, at card activation. You can use both.
